## CANVA BUILD INSTRUCTIONS

1. **Create new slide** (Blank layout)
2. **Add title** "Review-2 Focus" (Navy Blue, 48pt Bold, left-aligned)
3. **Add green bar** below title (4px height, full width, #2ECC40)
4. **Add 5 text boxes** stacked vertically:
   - Add rounded rectangle shape behind each text
   - Set background to White
   - Set border to Light Gray (1px)
   - Set corner radius to 8px
   - Type the numbered text inside (14pt Regular, Dark Gray)
5. **Set spacing** consistently between boxes (12px gap)
6. **Set slide background** to off-white (#F8F8F8)
7. **Preview** and adjust spacing if needed
8. **Export** when complete
